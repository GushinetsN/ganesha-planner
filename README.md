# Ежедневник Ганеши

Интерактивный прототип ежедневника с календарём, задачами, проектами и людьми. Нажмите на Ганешу, чтобы открыть меню разделов.

[Открыть ежедневник](https://gushinetsn.github.io/ganesha-planner/)

Встроенные записи демонстрационные. Созданные и изменённые записи хранятся только в браузере, в котором вы их внесли.

Для локального запуска нужен любой статический HTTP-сервер. Например, выполните в корне репозитория `python -m http.server 8000` и откройте [локальную страницу](http://127.0.0.1:8000/).
